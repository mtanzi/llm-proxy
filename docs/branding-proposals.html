llm-proxy branding proposals

Three name, icon and colour directions for the UI. The neutral greys stay as they are; only the accent and the second colour change, so each brand keeps the dense dark look the UI already has while dropping the Linear indigo it currently borrows.

Current accent #7c85f2 (Linear indigo) neutrals #0f1011 #16171a #8a8f98

Chosen: Spyglass, dark and light

Same structure and tokens in both themes. In light mode the brass and teal are darkened so text and badges keep readable contrast on white; the neutrals shift to warm off-whites that suit the brass.

Spyglass icon options

Five simple marks, each built from two or three strokes on a 32-unit grid so they stay clear as a 16px favicon. Brass is the stroke, teal is the single highlight. Each is shown on the dark and the light theme.
